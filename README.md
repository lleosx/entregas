# Entregas Lunardelli

App web para entregas em Lunardelli (PR): busca por rua e número, mapa próprio casa por casa, GPS e rota calculada no próprio app, com instruções por voz.

- Endereços: IBGE — Censo 2022, Cadastro Nacional de Endereços para Fins Estatísticos (CNEFE).
- Ruas: © colaboradores do OpenStreetMap (ODbL).

Acesse: https://lleosx.github.io/entregas/
